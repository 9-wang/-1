# 扣子智能体前端接入文档

版本：2026-04-25  
适用范围：Coze 开放接口（中国站）  
基础域名：https://api.coze.cn

## 0. 重要安全提示

1. 你在会话里暴露过访问令牌，建议立即在扣子后台重置该令牌。  
2. 前端浏览器代码中不要保存任何 Coze 令牌。  
3. 生产环境必须通过你自己的后端代理调用 Coze API，由后端注入 Authorization。

## 1. 接口总览

| 场景 | 方法 | 路径 |
|---|---|---|
| 获取智能体在线信息 | GET | /v1/bot/get_online_info |
| 发起对话（核心） | POST | /v3/chat |
| 查看对话详情 | GET | /v3/chat/retrieve |
| 查看对话消息详情 | GET | /v3/chat/message/list |
| 创建会话（可选） | POST | /v1/conversation/create |

## 2. 通用请求头

- Authorization: Bearer 你的访问令牌
- Content-Type: application/json

说明：线上建议使用 OAuth 访问密钥，不建议长期使用个人访问令牌。

## 3. 获取智能体在线信息

### 3.1 接口定义

- 方法：GET
- 路径：/v1/bot/get_online_info
- Query 参数：bot_id（必选，字符串）

示例请求：

    curl -X GET "https://api.coze.cn/v1/bot/get_online_info?bot_id=7632328598951051306" \
      -H "Authorization: Bearer YOUR_COZE_ACCESS_TOKEN" \
      -H "Content-Type: application/json"

### 3.2 返回处理建议

- 建议按以下结构做兼容解析：
  - code：0 表示成功
  - msg：错误或提示信息
  - data：业务数据
- 由于该接口文档页当前展示不完整，data 的具体字段请以前端实际返回为准，后端可直接透传。

## 4. 发起对话（核心接口）

### 4.1 接口定义

- 方法：POST
- 路径：/v3/chat
- Query 参数：conversation_id（可选）
  - 不传时，系统自动创建会话
  - 传入时，在指定会话继续对话（同一会话不能并发多个进行中的 chat）

### 4.2 Body 关键参数

必选参数：

- bot_id: String，智能体 ID
- user_id: String，用户标识（建议使用匿名业务 ID，不要用敏感主键）

高频参数：

- additional_messages: Array，对话消息数组
- stream: Boolean，是否流式返回
  - true：SSE 流式事件
  - false：非流式，仅返回 chat 元信息
- auto_save_history: Boolean，是否保存历史（默认 true）
  - 非流式场景必须为 true，否则后续无法查结果

高级参数：

- custom_variables: Map<String, String>，Prompt 变量
- parameters: Map<String, Any>，对话流开始节点自定义参数
- meta_data: Map，自定义附加信息
- extra_params: Map<String, String>，附加参数（如经纬度）
- shortcut_command: Object，快捷指令
- enable_card: Boolean，问答节点卡片返回开关
- publish_status: String，published_online 或 unpublished_draft
- bot_version: String，指定智能体历史版本

### 4.3 additional_messages 单条消息结构

- role: user 或 assistant
- content: 消息内容
- content_type: text 或 object_string
- type: question / answer / function_call / tool_response（按场景）

建议：

- 最后一条消息尽量是 role=user
- 首次对话且无会话历史时，必须通过 additional_messages 传入用户问题

### 4.4 流式请求示例

    curl --location --request POST "https://api.coze.cn/v3/chat?conversation_id=YOUR_CONVERSATION_ID" \
      --header "Authorization: Bearer YOUR_COZE_ACCESS_TOKEN" \
      --header "Content-Type: application/json" \
      --data-raw "{
        \"bot_id\": \"YOUR_BOT_ID\",
        \"user_id\": \"u_10001\",
        \"stream\": true,
        \"auto_save_history\": true,
        \"additional_messages\": [
          {
            \"role\": \"user\",
            \"content\": \"你好，请介绍一下你自己\",
            \"content_type\": \"text\"
          }
        ]
      }"

### 4.5 流式事件（SSE）

常见事件：

- conversation.chat.created
- conversation.chat.in_progress
- conversation.message.delta
- conversation.message.completed
- conversation.chat.completed
- done（data: [DONE]）

前端建议：

- 用 conversation.message.delta 做打字机效果
- 以 conversation.message.completed（type=answer）作为最终答案
- 以 conversation.chat.completed 判断 chat 结束

### 4.6 非流式请求示例

    curl --location --request POST "https://api.coze.cn/v3/chat" \
      --header "Authorization: Bearer YOUR_COZE_ACCESS_TOKEN" \
      --header "Content-Type: application/json" \
      --data-raw "{
        \"bot_id\": \"YOUR_BOT_ID\",
        \"user_id\": \"u_10001\",
        \"stream\": false,
        \"auto_save_history\": true,
        \"additional_messages\": [
          {
            \"role\": \"user\",
            \"content\": \"帮我写一段活动文案\",
            \"content_type\": \"text\"
          }
        ]
      }"

## 5. 非流式结果查询链路

当 stream=false 时，推荐流程：

1. 调用 /v3/chat，拿到 chat_id 和 conversation_id
2. 轮询 /v3/chat/retrieve，直到 status 进入终态
   - completed / failed / canceled / requires_action
3. 如果 completed，调用 /v3/chat/message/list 获取 answer 内容

### 5.1 查看对话详情

- 方法：GET
- 路径：/v3/chat/retrieve
- Query：conversation_id（必选）、chat_id（必选）

### 5.2 查看对话消息详情

- 方法：GET
- 路径：/v3/chat/message/list
- Query：conversation_id（必选）、chat_id（必选）

说明：官方建议轮询频率不高于 1 次/秒。

## 6. 推荐的前后端架构

浏览器前端  ->  你的后端服务  ->  Coze API

后端职责：

- 注入 Authorization
- 控制重试和超时
- 统一错误码映射
- 对流式响应做透传

建议后端提供以下业务接口：

- GET /api/coze/online-info?botId=...
- POST /api/coze/chat/stream
- POST /api/coze/chat/non-stream
- GET /api/coze/chat/retrieve
- GET /api/coze/chat/messages

## 7. 后端代理示例（Node.js + Express）

依赖安装：

    npm init -y
    npm i express cors dotenv

环境变量 .env：

    COZE_TOKEN=YOUR_COZE_ACCESS_TOKEN
    COZE_BASE=https://api.coze.cn
    PORT=3000

server.js：

    import express from "express";
    import cors from "cors";
    import dotenv from "dotenv";

    dotenv.config();

    const app = express();
    app.use(cors());
    app.use(express.json());

    const COZE_BASE = process.env.COZE_BASE || "https://api.coze.cn";
    const COZE_TOKEN = process.env.COZE_TOKEN;

    if (!COZE_TOKEN) {
      throw new Error("缺少 COZE_TOKEN 环境变量");
    }

    async function cozeFetch(path, options) {
      const method = (options && options.method) || "GET";
      const query = (options && options.query) || null;
      const body = (options && options.body) || null;

      const qs = new URLSearchParams(query || {}).toString();
      const url = COZE_BASE + path + (qs ? "?" + qs : "");

      return fetch(url, {
        method,
        headers: {
          "Authorization": "Bearer " + COZE_TOKEN,
          "Content-Type": "application/json"
        },
        body: body ? JSON.stringify(body) : undefined
      });
    }

    app.get("/api/coze/online-info", async (req, res) => {
      try {
        const botId = req.query.botId;
        if (!botId) {
          return res.status(400).json({ code: -1, msg: "botId 不能为空" });
        }

        const resp = await cozeFetch("/v1/bot/get_online_info", {
          method: "GET",
          query: { bot_id: String(botId) }
        });

        const data = await resp.json();
        return res.status(resp.status).json(data);
      } catch (err) {
        return res.status(500).json({ code: -1, msg: err.message });
      }
    });

    app.post("/api/coze/chat/stream", async (req, res) => {
      try {
        const body = req.body || {};
        const conversationId = body.conversation_id || "";

        const requestBody = {
          bot_id: body.bot_id,
          user_id: body.user_id,
          stream: true,
          auto_save_history: body.auto_save_history !== false,
          additional_messages: body.additional_messages || []
        };

        if (!requestBody.bot_id || !requestBody.user_id) {
          return res.status(400).json({ code: -1, msg: "bot_id 和 user_id 为必填" });
        }

        const resp = await cozeFetch("/v3/chat", {
          method: "POST",
          query: conversationId ? { conversation_id: String(conversationId) } : null,
          body: requestBody
        });

        res.status(resp.status);
        res.setHeader("Content-Type", "text/event-stream; charset=utf-8");
        res.setHeader("Cache-Control", "no-cache");
        res.setHeader("Connection", "keep-alive");

        if (!resp.body) {
          res.write("event:error\n");
          res.write("data:{\"msg\":\"上游没有返回流\"}\n\n");
          return res.end();
        }

        const reader = resp.body.getReader();
        const decoder = new TextDecoder();

        while (true) {
          const chunk = await reader.read();
          if (chunk.done) break;
          res.write(decoder.decode(chunk.value, { stream: true }));
        }

        return res.end();
      } catch (err) {
        res.write("event:error\n");
        res.write("data:{\"msg\":\"" + String(err.message).replace(/"/g, "'") + "\"}\n\n");
        return res.end();
      }
    });

    app.post("/api/coze/chat/non-stream", async (req, res) => {
      try {
        const body = req.body || {};
        const pollIntervalMs = Number(body.poll_interval_ms || 1000);
        const pollTimeoutMs = Number(body.poll_timeout_ms || 30000);

        const chatResp = await cozeFetch("/v3/chat", {
          method: "POST",
          query: body.conversation_id ? { conversation_id: String(body.conversation_id) } : null,
          body: {
            bot_id: body.bot_id,
            user_id: body.user_id,
            stream: false,
            auto_save_history: true,
            additional_messages: body.additional_messages || []
          }
        });

        const chatJson = await chatResp.json();
        if (chatJson.code !== 0) {
          return res.status(200).json(chatJson);
        }

        const chatId = chatJson.data && chatJson.data.id;
        const conversationId = chatJson.data && chatJson.data.conversation_id;

        if (!chatId || !conversationId) {
          return res.status(200).json({ code: -1, msg: "缺少 chat_id 或 conversation_id", raw: chatJson });
        }

        const start = Date.now();
        let status = "created";
        let retrieveJson = null;

        while (Date.now() - start < pollTimeoutMs) {
          const retrieveResp = await cozeFetch("/v3/chat/retrieve", {
            method: "GET",
            query: {
              conversation_id: String(conversationId),
              chat_id: String(chatId)
            }
          });

          retrieveJson = await retrieveResp.json();
          status = retrieveJson && retrieveJson.data && retrieveJson.data.status;

          if (["completed", "failed", "canceled", "requires_action"].includes(status)) {
            break;
          }

          await new Promise(function (resolve) { setTimeout(resolve, pollIntervalMs); });
        }

        if (status !== "completed") {
          return res.status(200).json({
            code: 0,
            msg: "对话未完成或非 completed 终态",
            chat: chatJson,
            retrieve: retrieveJson
          });
        }

        const msgResp = await cozeFetch("/v3/chat/message/list", {
          method: "GET",
          query: {
            conversation_id: String(conversationId),
            chat_id: String(chatId)
          }
        });

        const msgJson = await msgResp.json();
        const answers = ((msgJson && msgJson.data) || []).filter(function (m) {
          return m && m.type === "answer";
        });

        return res.status(200).json({
          code: 0,
          msg: "",
          conversation_id: conversationId,
          chat_id: chatId,
          retrieve: retrieveJson,
          messages: msgJson,
          answer: answers.length ? answers[answers.length - 1].content : ""
        });
      } catch (err) {
        return res.status(500).json({ code: -1, msg: err.message });
      }
    });

    app.listen(process.env.PORT || 3000, function () {
      console.log("Server started");
    });

## 8. 前端调用示例

### 8.1 流式对话（打字机效果）

    export async function streamChat(payload, handlers) {
      const onDelta = handlers.onDelta;
      const onCompleted = handlers.onCompleted;
      const onError = handlers.onError;

      const resp = await fetch("/api/coze/chat/stream", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(payload)
      });

      if (!resp.body) {
        throw new Error("浏览器不支持流式读取");
      }

      const reader = resp.body.getReader();
      const decoder = new TextDecoder();
      let buffer = "";
      let currentEvent = "";

      while (true) {
        const part = await reader.read();
        if (part.done) break;

        buffer += decoder.decode(part.value, { stream: true });
        const lines = buffer.split("\n");
        buffer = lines.pop() || "";

        for (const raw of lines) {
          const line = raw.trim();
          if (!line) continue;

          if (line.startsWith("event:")) {
            currentEvent = line.slice(6).trim();
            continue;
          }

          if (line.startsWith("data:")) {
            const dataText = line.slice(5).trim();

            if (dataText === "[DONE]") {
              if (onCompleted) onCompleted();
              continue;
            }

            try {
              const data = JSON.parse(dataText);

              if (currentEvent === "conversation.message.delta" && data.type === "answer") {
                if (onDelta) onDelta(data.content || "");
              }

              if (currentEvent === "conversation.message.completed" && data.type === "answer") {
                if (onCompleted) onCompleted(data);
              }
            } catch (e) {
              if (onError) onError(e);
            }
          }
        }
      }
    }

### 8.2 非流式一键调用

    export async function chatNonStream(payload) {

        method: "POST",
        headers: { "Content-Type": "application/json" },

    }

## 9. 联调检查清单

1. 智能体已发布为 API 服务。  
2. 令牌权限包含 chat、getChat、listMessage（以及你要用到的其他权限）。  
3. 请求头中 Authorization 格式正确：Bearer 空格 令牌。  
4. 非流式调用时 stream=false 且 auto_save_history=true。  
5. 前端用户隔离策略明确：user_id 的生成规则固定。  
6. 对 requires_action 状态有处理预案（工具调用回填）。

## 10. 常见问题

- 401 / 403：令牌无效、权限不足或已过期。  
- 429：触发限流，增加重试退避并降低并发。  
- 4000：参数错误（如 publish_status 与 bot_version 组合不合法）。  
- 4016：同一 conversation 存在进行中的对话。  
- 5000：端插件相关场景参数不符合要求（常见于未保存历史）。
